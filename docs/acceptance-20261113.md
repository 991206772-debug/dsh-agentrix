- Windows、PowerShell 7、DSH Desktop 0.2.2-rc.1 安装版运行时；通过 Electron 的 Node 模式加载真实 AgentLoop、ToolRuntime、SubagentRuntime 和 JSONL 会话持久化。

- 模型调用需要现有凭据引用，通过内存提供给原生适配器，不复制凭据文件；输出脱敏，运行证据保留本地且不进入 Git 或安装包。

## 独立流程评审

已完成的三个自动分流样例没有发现必须修复的误委派、无效返工或范围扩散。小任务均为 0 子代理，分流理由与实际工作量一致。用户明确要求委派或独审的样例，按该要求检查派单准确性，不将其视为自动误委派。

主控派单将独立产物、输入、写入范围和验收条件分别写清；补充仅转发到相关原任务。返工只处理原问题和直接回归，已验收兄弟任务不重做。

少量重复目录检查、同义换行验收标准列为可选开销，没有造成额外代理或错误交付，不阻止本轮验收。原隔离工具的字面 grep、报告读取权限和缺少检查用 PowerShell 已修正；这些测试器差异造成的旧耗时不作为正常流程效率结论。

新主控的取消恢复样例有 7 次工具误调用后自行纠正，包括缺少参数、读取尚未生成的产物、任务返回后继续尝试纠偏、取消后先调用启动再改为重试。没有同参数循环、错误写入或重复派发。这些是已观察到的流程摩擦，不能据此宣称完全无摩擦；本轮将其列为可选交互改进，不自动扩大为重设计。

GLM Flash 最后返工样例的主控工具错误为 0，两名执行者各重复提交一次报告，被“报告已提交”保护拒绝；没有错误写入或额外派发。独立复核确认原问题及直接回归均通过，结论为“验证已通过，停止修改”。
